# What is likelihood

Likelihood measures the probability of observing specific data given a set of model parameters, serving as a key tool for comparing how well different distributions fit data. Unlike probability, which predicts future outcomes (sums to 1), likelihood assesses past data to evaluate parameter suitability. It is crucial in statistics for Maximum Likelihood Estimation (MLE). [1, 2, 3]  
Key Aspects of Likelihood:

- Definition & Difference from Probability: While probability refers to the chance of future events happening given a model (e.g., 50% chance of heads), likelihood evaluates the plausibility of parameter values given the observed data.
- Calculation: For discrete data, it is a probability; for continuous data, it is a probability density. If $L(\theta|x)$ is the likelihood function, $\theta$ represents parameters and $x$ the data.
- Statistics Application: Likelihood is used in estimating parameters (finding the most likely model for data) and in the Likelihood Ratio Test, which compares the goodness-of-fit of two nested models (e.g., assessing if adding a variable improves a model).
